# アニメーション版PPTXのルールと作り方

出典：デジタル庁デザインシステムウェブサイト https://design.digital.go.jp/dads/ のコンテンツを加工して作成

`scripts/dads_anim.py` を使い、DADS準拠のスライドに「フェードのみ・クリック進行」の
アニメーションを付ける。python-pptx にはアニメーションのAPIがないため、
スライドXMLへ `<p:transition>` と `<p:timing>` を直接書き込む（モジュールが処理する）。

## 1. 守るルール

DADSはWCAG 2.2に準拠しており、動きは最小限にする（例：カルーセルは「アニメーションしない仕様」）。

| 項目 | ルール |
| --- | --- |
| 効果の種類 | 登場のフェードのみ。飛び込み・拡大・回転・点滅・強調・退場は使わない |
| 画面切り替え | 全スライドにフェード（標準速度）。表紙・出典にも付けて揃える |
| 進行 | クリック進行が既定。`then()` の自動連続は1クリック内で2〜3秒以内に収める |
| 最終状態で完結 | 全要素を表示した状態だけで内容が伝わること。印刷・PDF・プレビューPNGは最終状態になる |
| 退場を使わない | 途中で消す演出は最終状態と矛盾し、配布資料で重なって読めなくなる |
| 意味を動きに頼らない | 「どこが変わったか」は色の帯・ラベル・位置でも示す（色だけにも頼らない） |
| クリック数 | 1スライド6回以下を目安。超えるならスライドを分ける（`check` が警告する） |
| 発表者ノート | クリック手順を書き残す（`apply()` が自動で追記する） |

## 2. API

```python
from dads_theme import *
from dads_anim import grab, Timeline, add_transition, code_block

tl = Timeline(slide)

with grab(slide) as g:                  # with 内で追加した図形を集める
    rect(slide, ...); block(slide, ...)
tl.click("カード1を表示", g.shapes)     # 1クリックで同時にフェード表示
tl.then(more_shapes)                    # 直前の表示が終わったら自動で続ける（同じクリック内）

tl.apply()                              # XMLへ書き込む。アニメーションなしのスライドも
                                        # Timeline(slide).apply() で画面切り替えだけ付ける
```

| 関数 | 用途 |
| --- | --- |
| `grab(slide)` | `with` ブロック内で `slide.shapes` に追加された図形を `.shapes` に集める |
| `Timeline.click(label, shapes)` | クリックで開始するグループ。`label` はノートとクリック手順の説明になる |
| `Timeline.then(shapes, gap=120)` | 直前の表示の終了後、`gap` ミリ秒おいて自動表示 |
| `Timeline.apply(notes=True, transition=True)` | XMLを書き込む。1スライド1回だけ |
| `Timeline.labels` | クリック手順のラベル一覧（manifestの出力などに使う） |
| `add_transition(slide, speed="med")` | 画面切り替えのフェードだけを付ける |
| `code_block(slide, x, y, w, lines, lh, pad, highlights)` | コード面と行ハイライト帯。`highlights[i]` を `click()` に渡すと行を順に強調できる |
| `code_line(slide, x, y, w, h, text)` | コード1行（キーワードをプライマリー色の太字に） |

### 注意

- **同じ図形を二回登場させない**（`apply()` が検出して止まる）。
- **最初から見せる図形は `click()` に渡さない**。見出し・フッター・表の枠などは静的に置く。
- **重ね順は作成順**。ハイライト帯のように文字の背面に出すものは、文字より先に作る
  （`code_block` は対応済み）。
- **グループ図形は使わない**。`grab` はトップレベルの図形だけを集め、`render_check.py` も
  グループの中身を描画しない。
- 表の「セル単位」「列単位」で出したいときは、セルごとに `grab` して図形リストを保持しておく。

## 3. 構成パターン

| パターン | クリックの割り当て |
| --- | --- |
| カードの順次表示 | カード1枚＝1クリック。最後に結論の帯を1クリック |
| プロセスフロー | 「矢印＋次のカード」を1クリックずつ |
| コード解説 | 説明する行のハイライト帯＋右側の注釈を1クリックずつ |
| 変換の過程（表→表） | 変換後の表の行を `click()`＋`then()` で1行ずつ自動表示し、次のクリックでグループ枠や結果 |
| 比較（Before/After） | Beforeを静的に置き、矢印＋Afterを1クリック |

## 4. 検証

アニメーション版では、通常の検証（`render_check.py`＋PNGの目視）に次を加える。

```bash
.venv/bin/python scripts/dads_anim.py out/<名前>.pptx
```

- スライドごとのクリック数・効果数を出力し、フェード以外の効果・存在しない図形の参照・
  二重登場を `ERROR`（終了コード1）、画面切り替えなし・クリック過多を `WARN` として出す。
- プレビューPNGは**最終状態**の描画。途中状態の見え方は確認できないので、
  クリック手順（出力・ノート）とPNGを突き合わせて「各クリックで何が出るか」を確認する。
- PowerPointを使える環境なら、開いて読み込めること・スライドショーでの動きを確認する。
  使えない場合は「動作は未確認」と報告する。
